Pick your firmware

Choose your machine's kinematics and download the matching grblHAL build. The only thing that needs a specific firmware is how many axes and whether you run a dual-motor gantry — everything else is set up later in RectaControl.

1 · How many axes?

The extra motor channels (M3, M4) become A/B axes or a dual-motor gantry.

2 · Dual-Y gantry?

A second Y motor (Y2) drives the other side of a gantry. It runs on a spare motor channel.

No — single Y motor

One motor per axis. Standard machine.

Dual-Y, one switch

Both Y motors move together and share a single home switch. No self-squaring.

Dual-Y, self-squaring auto-square

Each Y motor homes to its own switch, so the gantry squares itself. Needs two Y home switches.

5-axis uses both spare motor channels for A and B — no channel left for a dual-Y motor.

How to flash

  1. Hold the BOOT button, plug in USB-C — the board mounts as an RPI-RP2 drive.
  2. Drag the .uf2 onto that drive. The board reboots into grblHAL automatically.
  3. Or use RectaControl → Firmware and pick the .uf2 — no button-holding needed.

✓ Every build is fully-loaded

This picker only chooses kinematics. Every firmware ships with the board's full feature set — 0-10 V analog spindle, Huanyang / Delta / generic Modbus VFD drivers, laser mode, coolant/mist/vacuum, all isolated inputs, Ethernet, USB-C and microSD — and you pick which to use at runtime. All motion tuning — steps/mm, speeds, travel, soft/hard limits, homing, VFD choice — is done in RectaControl after flashing. No config file to hand-edit.

Need a different setup?

Dual-X or dual-Z gantry, a non-squaring 4-axis, or something more exotic? Any kinematics the board physically supports can be built to order — just tell us your machine.
