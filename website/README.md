# rectabot.org — RectaBot website

Static landing page + grblHAL configurator for RectaBot, served via GitHub Pages
at **rectabot.org** (org site `rectabot.github.io` + custom domain).

- `index.html` — landing page (zero build; Tailwind + fonts via CDN)
- `configurator/` — 5-step grblHAL settings generator (canonical source lives in
  `rectabot/RectaBot` → `Docs/configurator/`; copied here for deployment)
- `Brand_Assets/favicon.svg`, `favicon.svg` — icons
- `CNAME` — custom domain (rectabot.org)
