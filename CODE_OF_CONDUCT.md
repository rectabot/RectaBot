# Code of Conduct

RectaBot is a small, focused open hardware project. We keep this short because the rules are simple.

## Be respectful

- Treat other contributors and users with respect
- Disagree about technical decisions without making it personal
- Assume good intent until proven otherwise
- Help newcomers learn — everyone was new once

## Focus on the work

- Discussions should be about the project: hardware, firmware, documentation, use cases
- Off-topic political, religious, or personal arguments belong elsewhere
- If a conversation drifts, it's fine to suggest moving it to a separate channel

## What is not acceptable

- Harassment, insults, or discrimination based on any personal characteristic
- Sustained disruption of discussions or pull request reviews
- Publishing private information of others without consent
- Encouraging or threatening violence
- Spamming issues, PRs, or discussions for promotion or attention

## Enforcement

This is a solo-founder project. The maintainer will:

1. Remove offending content (comments, PRs, issues) without prior notice
2. Warn the contributor privately
3. Ban repeat offenders from the repositories

Decisions are final and at the maintainer's discretion. There is no appeals process — this project is too small for that overhead.

## Reporting

If someone is making the project unpleasant for you, email **hello@rectabot.org** with details. Reports are handled confidentially.

## Scope

This code applies in:

- GitHub issues, pull requests, discussions, and reviews across all RectaBot repositories
- Project email channels
- Any other official channel (when they exist)

It does not extend to private channels or unrelated venues.

---

*Inspired by the principle: the smaller the project, the simpler the rules.*
